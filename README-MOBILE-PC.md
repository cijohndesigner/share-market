CJ CRUZ PERSONAL TRADE TRACKER — SINGLE RESPONSIVE WEBSITE

This project is intended to serve both desktop and mobile from the same root-level HTML files.
Do not upload these files inside a separate `mobile/` folder.

GitHub upload guidance:
1. Back up the current repository before replacing files.
2. Copy the contents of this package into the ROOT of the Trading-plan-2026 repository, preserving the `css/` and `js/` folder structure.
3. Commit and push to the branch/folder configured for GitHub Pages (typically `main` / repository root).
4. Open https://cijohndesigner.github.io/Trading-plan-2026/ on both desktop and phone.
5. On mobile, verify the ☰ menu opens, the × button closes it, backdrop/Escape close it, and forms/tables/calendar remain usable.

Data note: the website uses browser localStorage. Existing records are browser-specific; keep a JSON backup before testing or changing project files. This package does not intentionally clear localStorage.
